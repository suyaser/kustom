## The scene this has to pass

Ten friends in Discord voice. Before Roll teams, an admin taps `Spin` on Tonight's Mode card once. It lands on
`Tanks only`. Everyone's Tonight page, the panel and the teams post in Discord say `Tanks only · Not rated`.
They pick tanks in the client (Kustom does not stop anyone). The game ends; the poster and the result post
say `Blue kept the rule. Red: Jinx isn't a tank.` Nobody's Rating moved, the Fearless pool did not grow, and
the card is back on the group's standing mode for the next game. One tap by one person; nobody else did
anything.

## 1. Decisions (product's, made in this brief)

### D1. Two layers: the standing mode and the next game's rule

- **Standing mode** (M14.29, unchanged): `Normal` or `Fearless`, on `group_modes`, stays until an admin
  changes it. New groups start on `Normal` (`0030`).
- **Rule** (new, M15): one of the rule options (class wars x5, region wars, later mirror match), set for **the
  next game only**, layered on top of the standing mode. At most one rule is pending per group.
- **The select on the card holds both.** Choosing `Normal` or `Fearless` sets the standing mode **and clears a
  pending rule**. Choosing a rule (or `Spin`) sets the pending rule and leaves the standing mode alone.

### D2. Lifecycle

```
standing mode ──(admin picks a rule, or Spin)──> rule pending ──(Roll teams)──> rule locked on the lobby
      ^                                              │                                 │
      │                                   (admin picks Normal/Fearless:          (game recorded)
      │                                    rule cleared)                               │
      └──────────────────────────────── back to the standing mode <───────────────────┘
```

1. **Pending.** An admin picks a rule or taps `Spin`. Stored on the group (a pending-rule column beside
   `group_modes`, platform's shape). Tonight, for everyone, shows the rule on the card from this moment.
2. **Locked at Roll teams.** When the lobby goes `balanced`, the server copies the *effective* mode (the
   pending rule if any, else the standing mode) **and the rated flag** onto the lobby. The teams post is
   built from that copy, so Discord is always true. **Reroll keeps the copy** (and region wars keeps its
   draw). If the teams come down (someone leaves), the copy goes with them; the rule is still pending on the
   group, and the next Roll locks it again (region wars draws again).
3. **Changes after Roll are for the next game.** While `balanced` or `in_game`, picking, spinning or flipping
   the rated switch updates the *pending* state only; the card says `Changes apply from the next game.` and
   the admin foot shows `Next game: Mages only.` This game keeps what it was rolled with.
4. **Consumed when the game is recorded.** The game is stamped with the lobby's copy (mode, rule payload,
   rated). The server then clears the group's pending rule **only if it is still the one that was locked**
   (compare and clear), so a rule queued mid-game survives. The card is back on the standing mode (or the
   newly queued rule). Announcer: `This game's rule is done. Back to Fearless.`
5. **Not consumed by:** a game with no rolled lobby (hand-made teams with no Roll, backfill, a game recorded
   with no lobby row): it gets the standing mode, rated by the standing default, and the rule stays pending.
   A **remake** or an **ARAM** game: stamped with its rule but checked and rated by the existing rules (never
   rated); **the rule stays pending** so the replay plays it. A lobby that goes `dropped` (no end-of-game
   block for two hours): the rule stays pending; a late block still finishes the game and consumes it.

**This also fixes an M14 mismatch.** Today `games.mode` is stamped at *record* time by the `0024` trigger, so
an admin who picks Normal mid-game changes the running game, while the card says `Changes apply from the next
game.` (05-design 8.4.2: "the running game keeps the mode and rated flag it started with"). From M15.3 the
lobby's copy at Roll wins for the standing mode too; the trigger stays as the fallback for games with no
lobby copy. Decision row R2.

### D3. Spin

- One secondary button, `Spin`, on the card's admin row beside the select. Admins and the owner only.
- **The server picks**, never the browser: first a family uniformly from the shipped families (class wars,
  region wars; mirror match only once Kustom opens its Blind Pick lobby itself, M17 follow-up), then an option inside it uniformly (one of the five classes).
  Weighting by family keeps Spin from landing on a class five times in six.
- **Excluded from the draw:** the exact rule of tonight's previous rule game (no `Tanks only` twice in a
  row), and any option that is not playable right now (D7: a class pool or region with too few open
  champions under Fearless). Normal and Fearless are never a Spin result; Spin always gives a rule.
- The result is a pending rule like any other: Realtime tells every open Tonight page; the card shows a short
  reveal in place (at most 1.5 s, `prefers-reduced-motion` shows the result at once). **No wheel page, no new
  route.** Spinning again replaces the pending rule; the room can groan and the admin can tap once more.
- Two admins spinning at once: last write wins, every page converges on the server's answer.

### D4. What ships first

Class wars (five options) end to end, then region wars, then mirror match. User-facing name is
**`Class wars`** (the user's words, 05-design 8.10); "class night" stays the milestone's working name. The
internal ids are `class`, `region`, `mirror` (M15.2's union).

- **Class wars**: `Tanks only`, `Marksmen only`, `Mages only`, `Assassins only`, `Supports only`. A champion
  counts if **any** of its Data Dragon tags is the class (not only the first tag). At 16.19.1: Tank 46,
  Marksman 33, Mage 75, Assassin 46, Support 43. No `Fighters only` (60 champions; it barely changes a game).
- **Region wars**: at Roll the server draws two different regions uniformly from those with **at least 8
  open champions** (stricter than the plan's five: five leaves the last picker no choice and often no
  support). At the research's numbers that is Ionia, Noxus, Freljord, Demacia, Zaun, Shurima, Shadow Isles,
  Void, Piltover, Bilgewater, Ixtal; Targon, Bandle City and `unaffiliated` are never drawn. Which side gets
  which is part of the draw. No merged regions (no "Piltover + Zaun") in M15.
- **Mirror match**: lane opponents play the same champion. Needs a Blind Pick lobby, which **the host opens by
  hand in League** (the user, Q2): `Start a lobby` makes a Draft Pick custom, where two people cannot take the
  same champion. While the next game's rule is mirror, Tonight puts one line **where `Start a lobby` sits** (the
  place the host looks to open the night) and that button is replaced by the line, because it would make the
  wrong lobby: `Mirror match next. Host: open a Blind Pick custom in League yourself. Start a lobby only makes
  Draft Pick.` The same line shows while filling (a lobby may already be open). **Spin leaves mirror out** until
  Kustom opens the Blind Pick lobby by itself (M17 follow-up), so the hand step only happens when an admin picks
  mirror on purpose. A mirror game played in a Draft lobby simply cannot be kept (every lane differs); it is
  checked and rated like any mirror game.

### D5. Rated: per-mode default, one switch, locked at Roll

- **Defaults:** `Normal` rated, `Fearless` rated, every class wars option **not rated**, region wars **not
  rated**, mirror match **rated**.
- **The switch (Q1, the user said yes 2026-10-04):** an admin may flip `Rated` on the card for **the next
  game only**, both ways, in every mode. Choosing a mode or spinning resets the switch to that mode's default;
  after the game is recorded it resets to the standing mode's default. It locks with the rest at Roll teams,
  so **nobody can un-rate a game after seeing the teams or the score**; the chip, the teams post and the
  poster say it to everyone.
- **One rule for what a not-rated game does**, the ARAM precedent: recorded, on the poster, the tape, game
  history, Stats, Fun, Games and a person's page; **never** in the rating fold, the board's counts, the
  calibration line, the Fearless pool, or role learning (M5.16/M5.17: a tanks-only game must not teach anyone
  that their main is top). Sit-out rotation counts it (it is still a game played tonight). Unlike ARAM, a
  not-rated Rift game **does** get a Discord result post, because the rule line lives there.

### D6. The post-game check

- **Broke the rule** = a seat whose champion is **known** to the mode's table and is **not** in that seat's
  side's pool (class wars: the class's champions; region wars: the side's region). Mirror match: a lane where
  both seats have a `detectedTeamPosition` and the two champions differ.
- **Unknown, never broken:** a champion missing from the table (a champion newer than the pin, a region row
  missing), a seat with no detected position (mirror), two seats on one side claiming the same position
  (mirror). The line says `couldn't check`, never `broke`.
- **Kept** = a side (or, in mirror, a lane) with no broken seat. Unknown seats do not stop a side from
  keeping the rule, but the line names them.
- **Nothing punitive.** The result stands, the rating move (in a rated mode) stands, nobody is flagged on a
  profile, no counter, no stat. Nobody overturns anything.
- **The line names champions, never players.** `Red: Jinx isn't a tank.`, not `Omar broke the rule.` The room
  knows who played Jinx; the bot does not need to say it.
- Where it shows: one line on the poster (under the result, above the rating changes) and one line on the
  Discord result post. Nowhere else (not the tape, not game history rows; the game page shows the same line).

### D7. With Fearless and with Normal

- **Standing Normal + rule:** the panel shows the rule's whole pool. After the game, back to Normal.
- **Standing Fearless + rule:** the panel shows the rule's pool **minus the Fearless bans** (`modePool`), with
  the banned ones folded underneath as Fearless already does; the card status reads `Tanks only · 12 open`.
  The check is against the rule only: picking a banned champion is Fearless's business, as today (humans ban
  from the list).
- **Too few to play:** under Fearless, a class whose open pool is under 10, or a region under 8, is shown in the
  select as disabled with ` (too few open)` and never drawn by Spin.
- **What a rule game adds to Fearless:** only rated Rift games feed the pool (D5's single rule). So a
  not-rated class or region game adds nothing (no game burns Ionia), and a rated mirror game adds its
  champions like any game: five distinct champions, because the pool is a set. **This answers open question 3
  without the user** (one rule, no special case); the user can overrule it.
- Choosing `Fearless` or `Normal` with a rule pending clears the rule (D1). Reset fearless is unchanged.

### D8. Per-group on/off: none in M15

Every group gets every shipped rule. There is no "enabled modes" setting and no new settings surface; Spin
draws from everything shipped and playable (D3). A group that hates a rule simply doesn't pick it, and an
admin re-spins. This **removes "the group's enabled modes" from M15.3** (plan changed openly, decision R5).
If a group asks, it becomes `M15.13+` with its own row (and it would live on the Mode card, not `/admin`,
per the 2026-10-03 Fearless row: night controls live on Tonight).

### D9. Out of M15 (decided here, confirmable in Q4)

- `Rest of tonight` (a rule lasting to the night boundary): out. One game is the rhythm break the research
  argues for; a second rule game is one more tap.
- Themed weekdays: out. A schedule is a setting someone has to find and maintain.
- Best of three: out of M15 (Q3). It reverses "every game gets a fresh roll" and would be its own milestone.
- Per-mode records (`Tank games: Ana 3-1`), any rule-breaker stat, merged regions, small themes (research #5),
  every other research mode (#4 to #15).
- **Any champion-select surface**: no overlay, no pool in the client, no reading `/lol-champ-select/*`, no
  companion change in M15 at all (M15.7 dropped).

*Recommendation: yes.* You asked for it; locking at Roll removes the "un-rated because we were losing"

**Q3. Best of three** (same ten, same teams, three games). *Recommendation: not in M15.* It reverses "every

## 3. Edge cases

| Case | Behaviour |
|---|---|
| Fewer than ten | The rule applies to whoever played; the check runs per seat. Rating eligibility is unchanged (whatever it is for a short game today). The rule is consumed. |
| More than ten | Sit-outs are unaffected by the rule; the check reads the ten who played. |
| Someone leaves after Roll | Teams come down; the lobby's copy goes; the rule stays pending; the next Roll locks it again (region wars redraws). |
| Companion disconnects mid-game | No block, the lobby goes `dropped` after two hours, the rule stays pending. A late block finishes the game with the lobby's copy and consumes the rule. |
| Unknown player | Irrelevant to the check (it reads champions). Seated, balanced, rated (or not) like anyone. |
| Champion newer than the pin, or missing from the region table | `couldn't check`, never `broke`. |
| Mirror seat with no position, or two seats claiming one lane | That lane is `couldn't check`. |
| Remake | Never rated (existing rule), no rule line, **the rule stays pending** for the replay. |
| ARAM | Never rated, no rule line, no Discord result (existing rule); the rule stays pending. |
| Game with no Roll (hand-made teams, backfill) | Standing mode, standing rated default, no rule line; the rule stays pending. |
| Admin picks a rule while `balanced` or `in_game` | Pending for the next game; admin foot says `Next game: <rule>.`; this game keeps its copy. |
| Admin picks Normal or Fearless with a rule pending | Standing mode set, rule cleared. |
| Two admins at once | Last write wins; Realtime converges every page. |
| Class pool or region too small under Fearless | Disabled in the select (`(too few open)`), never drawn by Spin. If it shrinks below the line after being picked, the rule stays (the admin chose it) and the panel shows what is open. |
| Member or visitor | Sees the card, the rule, the chip and the panel. No select, no Spin, no switch (not disabled ones: none). |
| No JS | The select and `Set mode` work as a form post (M14.30). `Spin` is a form post too and the page reloads on the result; no reveal. |
